# Backup policy

Store one folder per course or module. Preserve the most editable source available, plus a delivery export when one exists.

- Rise 360: retain the native course in Rise and use its **Send a copy** feature to move it between author accounts. Rise courses do not have a standalone `.story` authoring file.
- Storyline 360: retain the `.story` project and its associated source assets. Add a SCORM export as a separate delivery backup.
- Other authoring tools: retain the editable project/source format and any linked media, then keep a published SCORM or equivalent delivery package separately.
- Label exported SCORM/web packages as delivery backups. They preserve a runnable course, but are not substitutes for native editable source.

Each course folder should contain the source files that are actually available, exports, and a short README recording format, version/date, and any missing source items.
